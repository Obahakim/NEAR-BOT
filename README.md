# NEAR Agent

A TypeScript command-line agent for interacting with NEAR testnet.

## Requirements

- Node.js 20 or later
- npm

## Setup

```powershell
cd near-agent
npm install
npm run setup
```

Start the agent with:

```powershell
npm start
```

The local wallet keystore is stored in `near-agent/agent-keystore.json` and is intentionally excluded from Git. Keep wallet credentials and `.env` files private.
